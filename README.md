# Modul Fiqih Kelas 7 — Bab I: Thaharah

Situs statis (HTML + CSS) hasil transkripsi Modul Fiqih MTs Kelas 7, Semester Ganjil TP. 2026/2027 (LP. Ma'arif NU Kab. Jepara), Bab I: Thaharah.

## Struktur halaman
- `index.html` — Ringkasan bab, elemen, capaian pembelajaran, dan navigasi ke setiap sub-bab.
- `ketentuan-thaharah.html` — A. Ketentuan Thaharah
- `kedudukan-air.html` — B. Kedudukan Air dalam Bersuci
- `alat-selain-air.html` — C. Alat-alat Bersuci Selain Air
- `hikmah.html` — D. Hikmah Penggunaan Alat Bersuci (+ Rangkuman Bab)
- `asesmen.html` — Asesmen Formatif I (soal-soal latihan)
- `style.css` — Gaya tampilan bersama seluruh halaman

Setiap sub-bab diawali kotak **Ringkasan Bagian Ini** yang merangkum poin-poin utama sebelum materi lengkap ditampilkan.

## Cara publikasi ke GitHub Pages
1. Buat repository baru di GitHub, lalu unggah seluruh isi folder ini (jangan folder pembungkusnya, isinya langsung).
2. Masuk ke **Settings → Pages**.
3. Pada **Source**, pilih branch `main` dan folder `/root`, lalu simpan.
4. Situs akan tersedia di `https://<username>.github.io/<nama-repo>/`.

Tidak ada dependensi build — seluruh file adalah HTML/CSS statis yang siap diunggah langsung.
